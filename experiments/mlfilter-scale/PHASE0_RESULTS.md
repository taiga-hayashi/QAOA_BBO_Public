### XY の実装変更(利用者の判断、2026-10-20)

- 旧 compact 版が遅いのは、qarpx の `diagonal_unitary` が 2^n 要素の対角を 2^(n+1)−2 個のゲートに分解し、各ゲートが全状態に作用するため(計算量 O(4^n))。14 量子ビットでこの部分だけで 1.88 s
- One-Hot 上では FM の QUBO が「グループ単独の項 + グループ対の項」に厳密に分かれるので、コスト層をグループごと・グループ対ごとの小さな対角に分けた(`src/qarp_pair_xy.py`、`OpenQARPPairXYQAOA`)。すべてのゲートは引き続き OpenQARP で実行する
- 検証: 7 種類のグループ構成(2 のべきでない [3,3]、[2,5]、[16,3,4] などを含む)と深さ p=1〜3 で、旧版との確率の最大差 1.0e-15。L=6・7 の Phase 0 の run でも旧版との差 3.8e-16 / 1.2e-16。L=7 では 28 量子ビットの全状態 XY とも 2.8e-18 で一致
- 同じ Seed・予算での 1024 回探索の最良目的値は、旧版と 1e-13 以内で一致(L=6: 2.90423764823、L=7: 2.62622024058)

## 3. 計画への影響

### (a) 通常 QAOA は L=7 までが現実的

- 固定 FM の比較では 49 角度を評価する。L=7 は 1 Seed あたり約 6.9 時間(1 スレッド)。5 Seed はコアを分けて並列にできる(1 本 8.7 GiB)
- L=8 は 16 スレッドでも 49 角度で約 12.7 時間 / Seed かかり、1 本で 129 GiB を使うので同時に 1 本しか動かせない。5 Seed で約 64 時間
- L=8 の通常 QAOA では、制約を満たす状態の確率が 1 回評価で 2e-11(α=5、角度 (0.31, 0.27))

### (b) XY・SA・Random は L=10 まで計算できる見込み

- XY(新版)の角度 1 回は L が 1 増えるごとに約 4〜5 倍。外挿で L=9 は約 0.5 s、L=10 は約 2.5 s(1024 回探索は約 45 分)
- 全列挙は L=9 で約 30 分、L=10 で約 2 時間(1 コアあたり。候補を分割すれば並列化できる)

### (c) 問題の構造上の注意(重要)

- SiO2 の屈折率(1.43〜1.49)は基板(1.45)とほぼ同じで、基板側に SiO2 を足してもスペクトルがほとんど変わらない
- 実際に L=8 の最良構造は L=7 の最良構造の末尾に SiO2 を足したもので、FOM の差は 1.6e-6 しかない。L=8 の上位 5 候補も、L=7 の最良構造を 1 層ずらしたものか、端に SiO2・Al2O3 を足したもの
- 2 位との差: L=6 は 4.1e-4、L=7 は 9.1e-2、L=8 は 3.9e-3
- このため、L を増やしても「候補数が増えた別の難しい問題」とは限らず、L=7 の解をほぼ含む問題になる。計画の H1(空間が広がっても α=1〜3 が速い)を解釈するときの前提として扱う必要がある
- 対処案(いずれも問題の定義を変える判断なので未決定): ① 基板の屈折率や層の厚さを変える、② 層ごとに厚さを変えて SiO2 の層が見えなくならないようにする、③ 最適解への到達ではなく regret(最適値との差)で評価する

### (d) FM の精度の手がかり(1 Seed のみ)

- 初期 40 点で学習した FM の「未評価の中での予測最小」の真の順位: L=6 は 237 位 / 4,096、L=7 は 872 位 / 16,384、L=8 は 1,479 位 / 65,536
