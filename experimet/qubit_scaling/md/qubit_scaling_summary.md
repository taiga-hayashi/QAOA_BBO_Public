# 量子ビット数スケーリング解析（検証済み範囲）

## 計算範囲

対象は，4選択肢のOne-Hotブロックを持つQUBOである．状態空間の大きさは解析的に全空間 $2^N$，実行可能部分空間 $4^{N/4}=2^{N/2}$ と計算した．

性能値は実際に状態ベクトル計算を実行した範囲だけを報告する．

| 手法 | 性能値を計算した範囲 |
| --- | --- |
| Standard QAOA（p=1，離散パラメータ探索） | $N\leq16$ |
| FM-XY-QAOA（One-Hot部分空間） | $N\leq16$ |
| FMQA（SA） | $N\leq64$（ただし最適性gap・最適解到達率は厳密最適値のある $N\leq32$ のみ） |

$N>16$ のFM-XY-QAOA と Standard QAOAについては，この環境で OpenQARP の厳密全状態ベクトル実行を完走・検証していないため，実行時間，制約充足率，最適解到達率，最適性gapを推定していない．JSONでは `null` として保存し，性能比較図からも除外する．

## 解釈上の注意

- 部分空間サイズの指数的な削減は組合せ論的に厳密であるが，それだけで各アルゴリズムの最適解確率や量子優位性は結論できない．
- FM-XY-QAOAは，採用したブロック内XYミキサーとOne-Hot初期状態のもとで，部分空間内に留まる．これは制約保存性の主張であり，最適性の保証ではない．
- 本実験は古典シミュレーションの計算資源制約を示すものであり，実機量子計算が必然・不可欠であることを示すものではない．
- 手法間の性能比較は，目的関数が異なるN間ではなく，同じNかつ実測済みの範囲で読む．
