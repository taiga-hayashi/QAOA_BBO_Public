# Standard QAOA ペナルティ係数 $\lambda$ 感度解析 実証実験サマリーレポート

本レポートは、`experimet/std_qaoa_sensitivity/` フォルダにおいて実施した、**Standard QAOA（横磁場 X-ミキサー型 QAOA, $p=1$, 全ヒルベルト空間 $2^{16} = 65,536$ 次元）** に対するペナルティ係数 $\lambda$ の感度解析です。変分パラメータは11×11の離散グリッドで探索しており、連続パラメータにおける大域最適化ではありません。

---

## 1. 実験概要と目的

### 1.1 背景：古典アニーリング (FMQA) と 量子アルゴリズム (QAOA) におけるペナルティの差異
前回の FMQA（Simulated Annealing）の感度解析では、$\lambda$ のスイートスポット（健全稼働領域：$\lambda_{\mathrm{crit}} \le \lambda \le 1.3 \lambda_{\mathrm{crit}}$）を適切に選定すれば、制約充足率を **100.0% に完全回復** させることが可能でした。
しかし、**Standard QAOA** においては、古典局所探索とは根本的に異なる量子力学的制約が生じます：

1. **全ヒルベルト空間への振幅散逸（Exponential Subspace Dilution）**:
   - $N=16$（4グループ × 4選択肢）の One-Hot 制約問題において、全状態数は $2^{16} = 65,536$ 通りであるのに対し、制約を満たす有効状態はわずか $4^4 = 256$ 通り（有効状態比率は **$0.39\%$**）です。
   - Standard QAOA が採用する横磁場ミキサー $H_M = \sum_{i=1}^n X_i$ は、状態ベクトルを全ヒルベルト空間（$65,536$ 次元）に一様に回転・拡散させるため、浅い回路（$p=1$）ではペナルティ項 $\lambda H_{\mathrm{pen}}$ を印加しても確率振幅を $0.39\%$ の有効解部分空間に局在化させることが本質的に極めて困難です。
2. **位相干渉ランドスケープの歪み**:
   - コストハミルトニアン $H_C = H_{\mathrm{obj}} + \lambda H_{\mathrm{pen}}$ において、$\lambda$ を大きくするとペナルティ項の固有値差が目的関数項の結合スケールを圧倒し、QAOA の位相回転角度 $\gamma$ の探索ランドスケープが制約違反ペナルティによって埋め尽くされ、目的関数の大域最適化に必要な干渉効果が破壊されます。

### 1.2 実装・シミュレーション条件
- **問題規模**: $N = 16$ 量子ビット（$2^{16} = 65,536$ 次元状態ベクトルをフル厳密計算）
- **対象ベンチマーク関数**:
  - **BB-1 (Materials Catalyst)**: 強結合相互作用（$|Q_{ij}| \le 6.0$、理論閾値 $\lambda_{\mathrm{crit}} = 6.54$、真の大域最適値 $f^* = -15.7736$）
  - **BB-2 (Random Fully-Connected)**: 全結合ランダムモデル（結合 $|Q_{ij}| \le 1.0$、理論閾値 $\lambda_{\mathrm{crit}} = 2.52$、真の大域最適値 $f^* = -5.8090$）
- **$\lambda$ スキャン範囲**: $\lambda \in [0.5, 25.0]$（全 18 点）
- **変分パラメータ最適化**: 各 $\lambda$ ごとに $(\gamma, \beta) \in [0.05, 1.2] \times [0.05, 1.2]$ の系統的グリッド最適化
- **サンプリング**: 各点 1,500 Shots / サンプリング
- **欠測の扱い**: 実行可能サンプルが0件の点では、有効最良・有効平均エネルギーを `—` とする。実行不可能解の目的関数値はこれらの統計量に含めない。

## 3. 主要な数理的発見と考察

### 3.1 発見1：制約充足率の壊滅的低迷（全空間散逸の証明）
- 完全ランダムな状態における有効解の存在確率は $256 / 65536 = \mathbf{0.39\%}$ です。
- このp=1・11×11グリッドの実験では、制約充足率は高々 **$3.85\%$ (BB-1) / $8.14\%$ (BB-2)** でした。
- つまり、**全測定ショットの $91.9\% \sim 99.9\%$ が制約違反の無効状態として破棄** されます。
- この設定では横磁場ミキサーによる全空間探索とペナルティの組合せが低い充足率を示した。これを任意深さ・任意の変分最適化・一般のOne-Hot問題に対する不可能性定理として解釈してはならない。

### 3.2 発見2：真の大域最適解到達率 $P(x^*)$ の極小化と量子干渉の乱れ
- Standard QAOA の最適解到達率 $P(x^*)$ は、全スキャン領域を通じて **$0.0001\% \sim 0.248\%$** という極めて微小な値にとどまります。
- 1,500 ショットのサンプリング実験においても、最適解が観測されるのは 0 回〜3 回程度であり、探索手法としての信頼性は皆無です。
- さらに、$\lambda$ の増加に対して $P(x^*)$ は単調に改善せず振動を示す（例：BB-1の $\lambda=12.0,14.0,16.0$）。目的関数項とペナルティ項はともに対角で互いに可換であり、この挙動はそれらの「非可換性」ではない。コストユニタリとXミキサーの非可換な時間発展、および離散グリッド探索の影響を含む結果として解釈する。

## 4. 結論

この実験設定では、p=1のStandard QAOAよりも部分空間保存ミキサーの方が高い制約充足率と最適解到達率を示した。これは有望な比較結果だが、量子優位性、実用性、またはXYミキサーの一般的不可欠性を完全に証明するものではない。異なる深さ、連続パラメータ最適化、複数インスタンス・seed、実機ノイズ下での追加検証が必要である。
