# BBO-QAOA プロジェクト構成

本プロジェクトは、未知のブラックボックス関数（真の目的関数）に対して、**Factorization Machine (FM) を用いたサロゲート（代理）モデル**を学習させ、そのFMをQUBO形式に変換した上で**QAOA (量子近似最適化アルゴリズム)**を用いて最適化を行う、「量子・古典ハイブリッド型のブラックボックス最適化 (BBO) パイプライン」です。

## ディレクトリ・ファイル構成

### 1. メインスクリプトと設定
- **[`main.py`](./main.py)**
  プロジェクトのエントリポイント（実行スクリプト）。全体のBBO（ブラックボックス最適化）ループを制御します。
  1. 初期データの生成
  2. FMモデルの学習
  3. FMパラメータからのQUBO構築
  4. QAOAによるQUBOの最適化（次の一手の提案）
  5. 真の関数による評価とデータセットの更新
  というサイクルを回し、最後に結果のプロットやJSON/CSVでの保存を行います。

- **[`config.yaml`](./config.yaml)**
  実験用パラメータを管理する設定ファイル。次元数(`d`)、学習エポック数、QAOAのレイヤー数(`qaoa_reps`)やオプティマイザ(`qaoa_optimizer`)などを一元管理しており、ソースコードをいじらずに実験条件を変更できます。

### 2. モジュール（機能別ファイル）
- **[`bb_function.py`](./bb_function.py)**
  「真のブラックボックス（BB）関数」に関する処理をまとめたモジュール。
  検証用としてランダムなQUBO行列をBB関数と見立てており、BB関数の評価（`evaluate_bb`）や、初期データセットの生成、また性能評価用の「厳密な最小値の計算（全探索）」などの関数を含みます。

- **[`fm.py`](./fm.py)**
  PyTorchによる **Factorization Machine (FM)** のモデル定義クラス。
  入力データに対して1次（線形）の重みと、2次（相互作用）の重みを計算し、代理モデルとしての予測値を出力します。

- **[`fm_to_qubo.py`](./fm_to_qubo.py)**
  学習済みのFMモデル（`TorchFM`）から重みパラメータを抽出し、**QAOAで解けるQUBO（二次制約なし二値最適化）形式の辞書**に変換するモジュールです。

- **[`qaoa_solver.py`](./qaoa_solver.py)**
  Qiskitを用いて、QUBO辞書をQAOAで解くためのソルバーモジュール。
  高速なC++シミュレータである `qiskit-aer` (`AerSampler`) とトランスパイラを利用して、設定された古典オプティマイザ（COBYLA等）と連携しながら量子最適化を実行します。

- **[`utils.py`](./utils.py)**
  プロジェクト全体で利用される汎用的なヘルパー関数群。
  - `Logger`クラス: ターミナルの標準出力へのprint表示と同時に、テキストファイル（`result/txt/`）にもログを書き出すためのクラス。
  - `get_fm_minimum`: FMモデル自体の（予測上の）厳密な最小値を全探索で求めるデバッグ・分析用関数。

### 3. 出力ディレクトリ（自動生成）
プログラムを実行すると、`result/` フォルダが作成され、拡張子ごとに結果が整理して保存されます。
- **`result/txt/`**: 実行時のターミナルログがそのままテキスト形式で保存されます。
- **`result/json/`**: 提案された解の履歴や予測値、真の評価値などの構造化データが保存されます。
- **`result/csv/`**: グラフ作成などに使いやすいCSV形式の推移データが保存されます。
- **`result/png/` & `result/pdf/`**: 最適化の推移（履歴）を可視化したグラフ画像が保存されます。
