# 03. 比較手法の定義と問題設定・公平条件

## 1. 比較手法の定義（4手法）

| 手法名 | 略称 | アルゴリズム分類 | ペナルティの扱い | Mixer / 初期状態 | プロット識別 |
| :--- | :---: | :---: | :--- | :--- | :--- |
| **`Adaptive-FMQA`** | 手法1 | 古典SA | FMQA反復ごとに適応的に更新 ($\alpha_t$) | 古典サンプラー | **青色の丸** ($\bullet$, `o`, blue) |
| **`LargePenalty-FMQA`** | 手法2 | 古典SA | 大きな固定ペナルティを使用 ($\alpha=100$) | 古典サンプラー | **オレンジ色の四角** ($\blacksquare$, `s`, orange) |
| **`Penalty-FMQAOA`** | 手法3 | 量子QAOA | Cost Hamiltonian へペナルティ加算 ($\alpha=5$) | 標準 X-Mixer / 均等重ね合わせ | **赤色の三角** ($\blacktriangle$, `^`, red) |
| **`XY-FMQAOA`** | 手法4 | 量子QAOA | **ペナルティなし** ($\lambda=0$) | **XY-Mixer (Ring)** / 各グループ **W-state** | **緑色のひし形** ($\blacklozenge$, `D`, green) |

## 2. 問題設定

- **符号化**: 1設計位置につき 3選択肢の One-Hot 符号化（各グループで $\sum_{i=1}^3 x_i = 1$）
- **ビット数**: $N \in \{6, 9, 12, 15, 18, 21, 24, 27\}$
- **One-Hot グループ数**: $G = N / 3 \in \{2, 3, 4, 5, 6, 7, 8, 9\}$
- **QAOA 回路深さ**: 主実験では $p = 1$
- **スケール制約**: 最大ビット数は $N=27$（$N=28$ は主比較に含めない）

---

## 3. 公平な比較条件（フェアネス基準）

全手法で以下を完全に統一・共通化すること：
1. **初期解（初期候補点）の同一性**: 同一 Problem ID および乱数 Seed において完全同一の初期解集合を使用。
2. **同一の初期学習データ**: 初期サンプリング点（例: 20点）とその評価値を全手法で共有。
3. **同一の Factorization Machine (FM) モデル構造**: 潜在次元 $k=2$ などのハイパーパラメータを統一。
4. **同一の FM 学習条件**: エポック数、Optimizer（Adam）、学習率などを統一。
5. **同一のブラックボックス（BB）関数評価予算**: 同一の評価回数予算（例: 初期20 + BBO 30回 = 50回）。
6. **同一のランダム Seed 集合**: 例: `seed = 42, 101, 2024`。
7. **同一の候補重複破棄ルール**: 過去に評価済みの同一候補が再生成された場合の破棄・再サンプリングルールを統一。
8. **QAOA 方式間の最適化条件同一性**: 深さ $p=1$ および変分パラメータ Optimizer 条件を統一。
9. ※共通化できない条件が存在する場合は、その理由を明記する。
