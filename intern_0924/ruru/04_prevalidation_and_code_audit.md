# 04. コード監査と事前検証（実機/シミュレータ）

## 1. コード監査項目
本実験開始前に、既存リポジトリ全体を精査し以下を特定・確認すること：

1. **FMQA ループのエントリーポイント**: 実験実行のメインフローの特定
2. **FM モデルの実装箇所**: サロゲートモデルの定義と学習ルーチン
3. **QUBO 生成処理**: FM パラメータからの QUBO 行列変換
4. **One-Hot ペナルティ生成部**: 制約ハミルトニアンの構成ロジック
5. **QAOA 回路生成部**: X-Mixer および XY-Mixer の実装妥当性
6. **W-state 初期状態生成部**: 各グループへの 3量子ビット W 状態生成
7. **Seed 管理および結果保存方法**: 再現性確保の仕組み
8. **既存コードの問題点と必要な最小変更の洗い出し・報告**: メモリ制約やスケール限界の把握

---

## 2. 事前動作検証 ($N=6, 9$)

本実験に入る前に、小規模サイズ（$N=6, 9$）で以下の厳密検証を実施し、全項目合格を確認すること：

- **制約充足確率 $P_{\text{feasible}}$ の計算**:
  $$P_{\text{feasible}} = \sum_{x \in \mathcal{F}} |\langle x | \psi \rangle|^2$$
  ※ $\mathcal{F}$ は One-Hot 実行可能状態の集合。
- **理想 Statevector での検証**:
  $P_{\text{feasible}} = 1$ となることを確認（許容誤差: $|1 - P_{\text{feasible}}| < 10^{-10}$）。満たさない場合は本実験へ進まない。
- **ビット順序と One-Hot グループ対応の検証**: ビットエンコーディング（MSB/LSB）の整合性確認。
- **W-state 初期化忠実度の確認**: 理想状態 $|\psi_0\rangle$ の忠実度。
- **XY 演算の対象量子ビットの確認**: Ring topology における最近接ペアの確認。
- **$XX+YY$ 項の係数と回転角の整合性確認**: 時間発展ユニタリの正確性。
- **ペナルティ関数の整合性**:
  - One-Hot 実行可能状態でペナルティ値が厳密に $0$ であること。
  - 制約違反状態でペナルティ値が厳密に正 ($>0$) であること。
- **QUBO エネルギーと Ising ハミルトニアン エネルギーの順序一致確認**: 変換時の定数項オフセットと符号の確認。
- **FMQA 最適探索と BB 評価回数の整合性確認**: 実験予算のカウント漏れ・二重カウント防止。
