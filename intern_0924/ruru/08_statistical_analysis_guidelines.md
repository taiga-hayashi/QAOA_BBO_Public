# 08. 統計処理基準

## 1. 代表値とばらつきの表記

- **中心値**: **中央値（Median）** を主指標とする（平均値は外れ値や歪んだ分布の影響を受けるため）。
- **ばらつき**: **四分位範囲 IQR（25パーセンタイル 〜 75パーセンタイル）** または **95% Bootstrap 信頼区間** で表記する。

---

## 2. ペア比較（Paired Comparison）

- 同一問題（BB-1, BB-2）、同一初期学習データ、同一乱数 Seed による**完全なペア比較**を実施する。
- 単純なグループ平均の比較ではなく、各 Seed 内での手法間差分 $\Delta R = R_A - R_B$ を評価する。

---

## 3. 有意差検定（Hypothesis Testing）

- **検定手法**: ノンパラメトリック検定である **Wilcoxon signed-rank test（対応のあるウィルコクソン符号付順位検定）** を採用する。
- **多重比較補正**: 複数手法・複数サイズ間の比較では、Bonferroni 補正または Benjamini-Hochberg 法による FDR 補正を適用し、有意水準（$p < 0.05$, $p < 0.01$ 等）を明記する。

---

## 4. データ除外（チェリーピック）の厳格な禁止

- 収束が遅かった試行や、探索に失敗した Run を任意に除外（Cherry-picking）しない。
- 失敗した試行がある場合は、その理由（制約違反、タイムアウト等）をログとして保存し、統計母集団に含めて客観的に報告する。
