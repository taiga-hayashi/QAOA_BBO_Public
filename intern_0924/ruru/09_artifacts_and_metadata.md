# 09. 保存物一覧とメタデータ管理

## 1. 保存すべき成果物一覧

数値実験の完全な再現性を担保するため、以下の成果物を指定形式で体系的に保存する：

1. **実験設定ファイル**:
   - YAML または JSON 形式でパラメータ（$N$, $G$, $\alpha$, seeds, 評価予算など）を明記。
2. **生データおよび集計データ**:
   - `intern_0924/results/{bb1, bb2}/*.json`
   - 全 Seed の候補軌跡、目的関数値、制約充足率、計算時間を完全記録。
3. **実行ログ**:
   - 警告（Warning）、オプティマイザの収束情報、失敗理由ログ。
4. **計算機環境メタデータ**:
   - OS・カーネルバージョン、CPU/GPUアーキテクチャ、メモリ容量。
   - Python バージョン、主要パッケージバージョン（`torch`, `numpy`, `scipy`, `matplotlib` 等）。
5. **再現性メタデータ**:
   - Git Commit Hash、実行ワンライナーコマンド、再現手順書（`REPRODUCIBILITY.md`）。
6. **可視化成果物**:
   - 論文用図（PDF, SVG）および確認用画像（PNG）（300 DPI）。
7. **学術報告ドラフト**:
   - `RESULTS.md`（客観的結果）、`DISCUSSION.md`（考察と限界）。
