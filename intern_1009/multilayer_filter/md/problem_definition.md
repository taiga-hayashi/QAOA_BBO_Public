# 多層光学フィルター：問題定義の確認

確認日: 2026-10-09。公開コードの静的読解。評価器は実行していない。

## 設計変数と符号化

層ごとにSiO2 / Si3N4 / Al2O3 / TiO2の4択。原公開コードは2ビット/層で00/01/10/11をこの順に対応させる。One-Hot化すると4L論理量子ビット。3層12ビット・6層24ビットは小規模検討案。原コードへの入力はカテゴリを元の2ビットへ変換するアダプタで接続する。コードのビット列とXY回路のビット列を同一と扱わない。

## 目的関数：論文とコードに相違あり

[arXiv:2407.20212v3](https://arxiv.org/html/2407.20212v3) Methods 4.8、式(6)の掲載式は

$$F_{paper}=10\frac{\int_{300}^{2500}[(T_{ideal}S)^2-(T_{designed}S)^2]d\lambda}{\int_{300}^{2500}S^2d\lambda}.$$

一方、[TMM_calculation.py保存版](../data/reference/TMM_calculation.py.txt) 74–75行は

$$F_{code}=10\frac{\sum_\lambda[(T_{designed}-T_{ideal})S]^2}{\sum_\lambda S^2}.$$

両者は代数的に異なる。論文もコードも最小化だが、前者の差の平方和ではない掲載式を後者へ無断で置き換えない。再現対象を論文式版・公開コード版に分け、採用を確定してから実装する。現在は未選択。ここでの指摘は静的照合であり、両者の性能差を測定した結果ではない。

## 公開コード版の固定パラメータ

9–25行、28–38行、58–63行を根拠とする。

| 項目 | 公開コードの値 |
|---|---|
| 波長 | 300〜2500 nm、1 nm刻み、2201点 |
| 入射 | 0度、p偏光 |
| 各設計層厚 | 50 nm |
| 上下媒質の屈折率 | 上1.4、下1.45 |
| 理想透過率 | 400〜750 nmで1、その他0 |
| 光学定数 | dielectric_ref.txtの4行、float32実数読込 |
| 重み | solar_spectrum.txt |

論文本文の全厚1200 nmを層数で分ける設定とは異なる。媒質のコメントより実際の代入値を優先して記録した。光学データとスペクトルは今回未取得であり、出所・形状・波長整合・利用条件は未確認。依存候補はnumpy、pandas、tmm_fast。バージョンと互換性は未検証。
