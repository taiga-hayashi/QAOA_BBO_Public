初期20件で学習済みの5つの23変数FMを凍結し、カテゴリを事前に定めて固定・削減した。N6は有機3択×ハロゲン3択、金属Sn固定。N9は有機3択×金属3択×ハロゲン3択。再学習と真値による角度選択は行わない。

標準X-MixerとRing XY-Mixerは共有OpenQARP実装、p=1。各探索の回路評価予算を9/9/49/361で一致させる。標準はα=1,5,30,100,1000、XYはλ=0。元のbase-S正規化と、ペナルティ込みCost全体を再正規化する対照を別設定として記録する。

N9・α5では元の9点から広域361点へ変更すると、標準base-Sの制約充足確率中央値は10.96%→18.61%、10ショットで実行可能FM最小解を少なくとも1回引く確率は7.91%→17.03%。XYの後者は32.96%→63.45%。Cost全体再正規化では充足率37.69%だがFM最小解獲得14.44%で、充足率だけでは品質を判断できない。5モデルの記述的比較であり、44検定のBonferroni補正後に有意差は認められない。
