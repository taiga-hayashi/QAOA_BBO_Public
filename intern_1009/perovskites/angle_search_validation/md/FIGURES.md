# 図の読み方

[比較図](../pdf/angle_search_validation_overview.pdf)は左列N6、右列N9。標準はα5。赤実線はbase-S、暗赤破線はfull-Cost-S、緑はXY λ0。線は5モデル中央値、帯はIQR。横軸は探索規則のカテゴリで、回路評価数に比例した間隔ではない。

- 上段: 選択した角度での1ショット制約充足確率。高いほど実行可能解を得やすい。
- 中段: 10ショット中に実行可能FM最小解を1回以上引く厳密確率。初期候補重複除外なし。
- 下段: 10ショット中に実行可能解を引けた条件で、最良FM予測値と実行可能FM最小値の差の期待値。低いほど良い。真の目的関数の差ではない。

元の9点はγ=[0.05,0.4,0.8]、β=[0.1,0.4,0.8]。広域はγ∈[0,2π]、β∈[0,π]を各軸3/7/19点に分割する。有限の検証範囲であり、任意のFMに共通する基本周期を主張しない。

[N6のα感度](../pdf/penalty_scale_feasibility_N6.pdf) / [N9のα感度](../pdf/penalty_scale_feasibility_N9.pdf): 行はα=1,5,30,100,1000、列は4探索。左パネルbase-S、右パネルfull-Cost-S。色・数字は5モデル中央値の制約充足確率（0〜1）。αは固定λではなくλ/S。

全9図をPDF/SVG/PNGで出力した（27ファイル）。6つの各段・各Nの単独図も同じフォルダに保存。図中にタイトル・下部注釈は置かず、本書とファイル名で条件を明示する。PDFをPNGへレンダリングして比較図とN9ヒートマップの文字・凡例・目盛りを確認した。
