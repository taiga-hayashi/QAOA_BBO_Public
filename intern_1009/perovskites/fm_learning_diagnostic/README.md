# FM学習改善の初期診断

状態: **同じ初期20件の18条件×5Seed、90学習と独立照合が完了**。閉ループBBO、サンプラー計算、初期データ変更、正則化は未実施。

元の20件・同じ172未学習候補を固定し、ランク0/1/2/4、学習率0.1/0.01、120/1000epochsを比較。ランク2の2条件ではtrain mean/stdによる標準化も対照に追加。元のモデルと予測を完全再現してから計算した。共有FM学習・QUBO変換を使用し、共有コードには変更を加えていない。

元のrank2のTest RMSE中央値1.496 eVに対して、同じlr0.1/120epochsのrank1は0.903、相互作用なしrank0は0.706。順位相関はそれぞれ0.416/0.688/0.793。予測最小の未評価材料の真値中央値は3.391/2.231/1.800 eV。ランク2のepochsだけを1000へ増やしてもTest RMSEは1.493で、ほぼ改善しない。

初期20件では有機16カテゴリ中3〜6カテゴリが未観測。それらの一次係数と因子ベクトルは、元のモデルで初期値からの変化が厳密に0だった。

この結果はすでに閲覧したtestへの探索的比較。testで選んだ設定の独立した汎化性能を保証せず、最良条件を4手法の主設定へ自動採用しない。5Seed・51比較のBonferroni補正後に有意差は認められなかった。
