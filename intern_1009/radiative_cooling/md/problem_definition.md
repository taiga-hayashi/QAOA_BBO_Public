# 3材料の平面多層放射冷却：問題定義の確認

確認日: 2026-10-09。[原論文の保存PDF](../data/reference/1902.06573v1.pdf) MethodsおよびSupplementary Note Bを確認。評価器は未実装。

## 原資料にある平面問題

Supplementary Note B（PDF31ページ目、本文ページ番号30）は、SiO2/SiC/PMMAの5層平面構造、各層1 µm、全243候補のRCWA評価を扱う。この5層比較問題自体は原資料に存在する。9層への拡張と評価バックエンドのTMMへの置換は変更案として分ける。

原論文の主題であるパターン付きメタマテリアルには同一層内のSiO2/SiC混在禁止がある。セルごとの独立3択へ置き換えて同じ原問題とは呼ばない。

## 入出力と目的

入力はL層の材料列。材料順を[SiO2, SiC, PMMA]とするOne-Hot接続案ではN=3L。5層15ビット、9層27ビット。出力は放射率スペクトルから計算する無次元FOM。原資料Eq.(1)は最大化：

$$F=\langle\epsilon\rangle_{[8,13]}-\langle\epsilon\rangle_{[1,8]}-\langle\epsilon\rangle_{[13,20]},$$

$$\langle\epsilon\rangle_{[a,b]}=\frac{\int_a^b\epsilon_\lambda E_{b,\lambda}(T)d\lambda}{\int_a^b E_{b,\lambda}(T)d\lambda}.$$

波長単位はµm。各帯域をそれぞれ黒体放射で正規化する。共通の最小化比較ではf=−Fとする。冷却電力そのものを最大化する別目的と混同しない。

## 確認済み／未確認

PMMAの屈折率1.48、SiO2/SiCはPalikの光学定数を補間するという方法が記載されている。数値テーブルは未取得。FOM重みの温度、境界媒質、波長刻み、放射率評価の角度条件は評価器再現のため確定する必要がある。別の冷却電力計算の303 KをこのFOMの温度へ自動的に転用しない。

Supplementary Note Bの平面設定を参照し、TMMを採る場合は層順・境界・偏光等を合わせてRCWAの参照例と照合する。掲載FOMは文献値であり、このフォルダで再現した結果ではない。
