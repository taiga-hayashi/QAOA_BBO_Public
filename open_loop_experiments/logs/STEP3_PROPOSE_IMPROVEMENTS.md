# 3. 診断結果に基づく改善案の提案

## 診断結果のまとめ
- BB1/BB2 の N=18, 21 における `XY-FMQAOA` の挙動を詳細に分析した結果、提案候補と FM 上の厳密最小値の間の Solver Gap は、特に BB2 では `0.0000` になることが多く、XY QAOA は確実に FM 上の最適解を見つけ出していることがわかりました。
- しかし、その候補の真の評価値が悪い（目的値が高い）場合があり、これは代理モデル（TorchFM）の予測精度（順位付け精度）の低さが主因であることが判明しました（Top-5% Recall が 20% 台など）。

## 代理モデルの改善案
- 既存の TorchFM は `MSELoss` を用いて Epoch=120、L2正則化なしで学習していました。
- 外れ値の影響を減らし、かつ少ない初期点（20点）からの過学習を防ぐため、以下の組み合わせを提案・評価しました。
  1. `SmoothL1Loss` (Huber Loss) の導入
  2. Adam オプティマイザへの `weight_decay = 1e-2` (L2正則化) の追加
  3. 学習の安定化のため `epochs = 200` に延長
- **結果**: この改善済み FM を用いることで、N=18 の BB1 では Spearman 順位相関係数が 0.4250 から 0.6180 に、Top-5% Recall が 0.1892 から 0.3243 に劇的に改善しました。N=21 でも同等以上の精度を維持し、より安定した順位付けが可能になりました。
